# Checklists

## First print of a new part

- [ ] `build_part.py` printed `OK` and the preview looks right.
- [ ] Opened in Bambu Studio; the X2D profile and the correct plate are selected.
- [ ] Filament and AMS slot assigned for each body; support material assigned if used.
- [ ] Sliced preview checked layer by layer around overhangs and thin walls.
- [ ] Two-material part: it fits the narrower dual-nozzle area.
- [ ] Plate is clean and the right type for the filament.
- [ ] Watched the first layer finish before walking away.
- [ ] Measured the result and noted any tolerance change in the project README.

## First cut of a new job

- [ ] `check_svg.py` printed `OK`.
- [ ] Material is identified and has a `confirmed` row in `laser/materials.md`. If not: scrap test first.
- [ ] Material is not on the banned list.
- [ ] Imported into xTool Studio at the right size (measure one known dimension on screen).
- [ ] Each colour layer has its processing type and settings; order is print, score, cut.
- [ ] Print then cut: material taped flat at all four corners and not moved when swapping modules.
- [ ] Extraction and air assist running, lid closed.
- [ ] Extinguisher or fire blanket within reach.
- [ ] Stayed with the machine for the whole run.
- [ ] New settings that worked are added to `laser/materials.md`.
